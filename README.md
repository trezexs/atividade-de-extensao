# IA na Prática — Inteligência Artificial aplicada ao cotidiano

Plataforma web autoral desenvolvida para o **Projeto de Extensão Universitária** do curso de **Sistemas de Informação**.

O projeto reúne uma coleção aberta e gratuita de **6 guias práticos em PDF** voltados à democratização do acesso à Inteligência Artificial para cidadãos, estudantes, educadores, trabalhadores e pequenos negócios locais, alinhados aos Objetivos de Desenvolvimento Sustentável (ODS 4, 8, 10 e 11) da ONU.

---

## Volumes da Coleção

1. **Volume 1 — Inclusão:** *Inteligência Artificial e Transformação Social: Caminhos para uma Sociedade mais Inclusiva*
2. **Volume 2 — Educação:** *Inteligência Artificial na Educação: Novas Possibilidades para o Aprendizado*
3. **Volume 3 — Pequenos Negócios:** *Inteligência Artificial e Empreendedorismo: Inovação e Oportunidades para Pequenos Negócios*
4. **Volume 4 — Segurança Digital:** *Inteligência Artificial e Segurança Digital: Proteção, Ética e Responsabilidade*
5. **Volume 5 — Trabalho:** *Inteligência Artificial e o Futuro do Trabalho: Competências para uma Nova Era*
6. **Volume 6 — Comunidade:** *Inteligência Artificial e Desenvolvimento Comunitário: Soluções Tecnológicas para Desafios Locais*

---

## Tecnologias Utilizadas

- **React 18 + TypeScript + Vite**
- **Tailwind CSS** (Design editorial monocromático de alto contraste e acessibilidade)
- **Firebase (Cloud Firestore, Hosting & Google Analytics)** para coleta de validação acadêmica e indicadores de impacto social

---

## Como executar localmente

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Gerar versão de produção
npm run build
```
